# 🏠 Smart Real Estate Investment Advisor

A Machine Learning-powered web application that helps users estimate property prices and analyze real estate trends. This project combines **Data Analysis (EDA)** to understand market history and **Machine Learning** to predict future property values.

## 🔭 Project Overview
Buying a home is one of the biggest financial decisions a person makes. This tool aims to bring transparency to the process by:
1.  **Visualizing** historical pricing trends in different neighborhoods.
2.  **Predicting** the fair market value of a house based on features like square footage, location, and number of bedrooms.

The project is built entirely in the cloud using **Google Colab** for development and **Streamlit** for the user interface.

## 🌟 Key Features
* **Price Prediction Engine:** Enter house details (BHK, Location, Sqft) and get an estimated price instantly.
* **Interactive Dashboard:** Visualizations showing price distribution and location-based trends.
* **Data-Driven Insights:** Identifies which factors (e.g., proximity to city center) influence price the most.

## 🛠 Tech Stack
* **Language:** Python
* **Data Manipulation:** Pandas, NumPy
* **Visualization:** Matplotlib, Seaborn
* **Machine Learning:** Scikit-Learn (Linear Regression, Decision Trees)
* **Web Framework:** Streamlit
* **Development Environment:** Google Colab
